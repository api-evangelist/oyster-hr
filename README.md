Global employment platform with a REST API for hiring international employees, managing contracts, processing global payroll, and ensuring local compliance in 180+ countries. The API enables integration with HRIS and payroll systems, time-off management, expense management, invoicing, benefits, offboarding, and provides embeddable web components for partners and resellers.

**Areas:** Human Resources · Global Employment · Payroll · Employer of Record · Contractors · Compliance · Remote Work

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Oyster HR: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
